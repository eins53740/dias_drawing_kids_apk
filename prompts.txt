Create an Android APK for kids.

Build an app that helps children learn to draw, step by step. The app will include a set of drawings. Each drawing represents a member of the “Família Dias”.

Main flow

In the main menu, the child selects which family member they want to draw.

The child draws on paper using pencils. The app does not provide an on-screen canvas; it only guides the child through the drawing process.

Drawing guidance

Start with the basic outline: main lines, shapes, and borders.

Then move to colouring/shading, step by step (one area at a time, in a clear order).

Planning
